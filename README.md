# ÉLANE BEAUTY LOUNGE

### Beauty, thoughtfully yours.

ÉLANE BEAUTY LOUNGE is a premium salon website and appointment-management prototype designed for a modern ladies' beauty lounge.

## ✨ Features

### Customer Side
- Premium responsive salon website
- Service categories and pricing
- Service details
- Staff selection
- Appointment booking
- Date and time-slot selection
- Booking confirmation
- Printable appointment receipt
- Gallery with image preview
- Reviews
- Wishlist
- Offers and packages
- WhatsApp contact button
- Mobile-friendly design

### Owner Side
- Owner login
- Appointment dashboard
- Appointment search and filtering
- Appointment cancellation
- Revenue overview
- 14-day appointment calendar
- Service and pricing management
- Offers management
- Review management
- Gallery management
- CSV appointment export

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SessionStorage
- Google Fonts
- GitHub Pages

## 📅 Appointment System

Customers can select:

1. Service
2. Beautician
3. Date
4. Available time slot
5. Personal details

The system prevents an already-booked slot from being booked again for the same staff member.

## 💾 Data Storage

This prototype uses browser LocalStorage for appointment data.

Therefore, bookings are currently stored locally in the browser and are not shared between different devices.

## 🎯 Project Objective

The objective of this project is to demonstrate how a traditional salon appointment process can be converted into a simple digital system with both customer-facing and owner-management features.
